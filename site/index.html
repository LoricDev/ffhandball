Endpoints

Toutes les routes de données sont en GET et renvoient du JSON. Le détail des paramètres et des schémas de réponse est dans la documentation interactive ; la spécification complète est en OpenAPI.

Utiliser l'API

Premier appel

curl "/v1/clubs?q=metz&limit=5" \
  -H "Authorization: Bearer $FFHB_KEY"
const res = await fetch("/v1/clubs?q=metz&limit=5", {
  headers: { Authorization: `Bearer ${process.env.FFHB_KEY}` },
});
const { data, meta } = await res.json();
console.log(meta.total, data[0].nom);
import os, requests

r = requests.get(
    "/v1/clubs",
    params={"q": "metz", "limit": 5},
    headers={"Authorization": f"Bearer {os.environ['FFHB_KEY']}"},
)
r.raise_for_status()
print(r.json()["meta"]["total"])

L'API n'envoie pas d'en-têtes CORS : appelez-la depuis votre serveur, pas depuis le navigateur de vos visiteurs, pour ne pas exposer votre clé.

Règles à connaître

Clé API
Quand l'accès par clé est activé, envoyez-la dans Authorization: Bearer ffhb_… ou dans X-API-Key. Une clé absente, révoquée ou expirée renvoie alors 401. /health, /ready, /docs et /openapi.json n'en demandent jamais.
Pagination
Les listes prennent limit (100 maximum, 20 par défaut) et offset. La réponse contient data et meta avec total, limit et offset.
Quota
120 requêtes par minute, comptées par clé, ou par adresse IP sans clé. Les en-têtes X-RateLimit-Limit, X-RateLimit-Remaining et X-RateLimit-Reset indiquent où vous en êtes. Au-delà, 429 et Retry-After.
Erreurs
Le corps est { "error": { "code", "message" } }, avec les codes BAD_REQUEST, UNAUTHORIZED, NOT_FOUND, RATE_LIMIT_EXCEEDED, INTERNAL_ERROR et SERVICE_UNAVAILABLE.
Statut d'un match
a_jouer, joue, reporte, annule ou forfait. Le score reste null tant que le match n'est pas joué.

Projet indépendant, non affilié à la Fédération Française de Handball. Les données proviennent des sites publics de la FFHandball.
